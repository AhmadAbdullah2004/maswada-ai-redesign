# Maswada AI 

An AI-powered note-taking application that supports Arabic and English.

## Live Demo

[Try Maswada AI](https://maswada-ai-redesign.vercel.app)

- 💾 **Auto-save** — Automatically save changes while editing notes.
## Features

- User sign-in and sign-up
- Create, edit, and delete notes
- Automatic note saving
- AI tools for summarizing, rewriting, and translating text
- Arabic and English support
- Responsive user interface

## Technologies

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express
- **Database:** SQLite, Sequelize
- **Authentication:** Clerk
- **AI:** OpenAI API
- **Hosting:** Vercel and Render

## My Contribution

This project is based on an existing full-stack template. My main work focused on the frontend, connecting it to the backend, handling API requests, adding automatic saving, supporting Arabic and English, and publishing the application online.

## Setup

1. Clone the repository.
2. Install dependencies in the frontend and backend folders.
3. Set up the required environment variables.
4. Initialize the database and run both applications.
