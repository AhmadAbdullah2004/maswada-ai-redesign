# Maswada AI

An AI-powered note-taking app with Arabic and English support.

## Live Demo

[Try Maswada AI](https://maswada-ai-redesign.vercel.app)

## Features

- User authentication
- Create, edit, and delete notes
- Automatic saving
- AI-powered summarization, rewriting, and translation
- Arabic and English support
- Responsive design

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express
- **Database:** SQLite, Sequelize
- **Authentication:** Clerk
- **AI:** OpenAI API
- **Deployment:** Vercel, Render

## My Contribution

Based on an existing full-stack template, with a focus on frontend development, API integration, automatic saving, bilingual support, and deployment.
